# Project_Graphes

Список участников:

Кекин Илья Вячеславович АТ-04,
Федорахин Константин Николаевич АТ-04

Павел работал над визуализацией графиков, парсингом, функциями масштабирования, реализацией DI-контейнеров и точек расширения. Константин работал с исключениями и отдельным классом для сборки DI. Задачей Ильи была реализация сохранения и загрузки результата в разных форматах.

Проект направлен на решение проблемы визуализации и графов / графиков.
Основные сценарии использования:
1) Студент хочет понять, как выглядит график функции или как меняется его форма, для этого в приложении строит график по введенной формуле.
2) Преподаватель хочет наглядно продемонстрировать студентам график какой-либо функции, для этого в приложении строит функцию и использует полученную визуализацию.

Основные инструменты: .NET 8 SDK, C#, AvaloniaUI
